# daten1 — игровые прототипы

Репозиторий объединяет браузерные игровые прототипы и заметки о разработке игр. Здесь есть отдельные HTML-примеры 2D- и 3D-игр, включая Space Shooter, а также материалы о жанрах и минимальном процессе разработки.

Для начала см. `minimal-game-development.md`; примеры находятся в `space-shooter-game.html`, `space-shooter-3d.html` и других HTML-файлах.
