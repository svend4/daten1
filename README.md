# Flower Shop - 7 Levels 🌹

Магазин цветов с 7 уровнями сложности - от простого PHP до enterprise микросервисов.

## 🚀 Quick Deploy на Railway

Все 7 уровней готовы к деплою на Railway!

**📖 Полное руководство:** См. [RAILWAY_DEPLOYMENT_GUIDE.md](./RAILWAY_DEPLOYMENT_GUIDE.md)

## 📦 Уровни

| Level | Ветка | Технологии | Сложность |
|-------|-------|------------|-----------|
| 1 | `claude/level1-TDUEs` | PHP + SQLite | ⭐ |
| 2 | `claude/level2-TDUEs` | Flask + SQLite | ⭐⭐ |
| 3 | `claude/level3-TDUEs` | Django | ⭐⭐⭐ |
| 4 | `claude/level4-TDUEs` | Node.js + Express | ⭐⭐⭐ |
| 5 | `claude/level5-TDUEs` | React + Flask API | ⭐⭐⭐⭐ |
| 6 | `claude/level6-TDUEs` | Next.js + TypeScript | ⭐⭐⭐⭐⭐ |
| 7 | `claude/level7-TDUEs` | Microservices | ⭐⭐⭐⭐⭐⭐ |

## 🎯 Быстрый старт

1. Выберите уровень из таблицы
2. Перейдите на [railway.app](https://railway.app)
3. Deploy from GitHub → выберите нужную ветку
4. Готово!

Подробные инструкции в [RAILWAY_DEPLOYMENT_GUIDE.md](./RAILWAY_DEPLOYMENT_GUIDE.md)
