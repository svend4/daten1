# Railway Deployment Guide - Level 3 (Django)

## Quick Deploy

1. Go to [Railway](https://railway.app)
2. Click "New Project" → "Deploy from GitHub repo"
3. Select repository: `svend4/daten1`
4. Select branch: `claude/level3-TDUEs`
5. Railway will automatically detect and deploy Django application

## Configuration

- **Runtime**: Python 3.x
- **Framework**: Django 5.x
- **Web Server**: Gunicorn
- **Static Files**: WhiteNoise
- **Database**: SQLite (default)
- **Port**: Automatically assigned by Railway

## Environment Variables

### Required
- `SECRET_KEY` - Django secret key (will be auto-generated by Railway)

### Optional
- `DEBUG` - Set to "True" for debug mode (default: False)

## Post-Deployment

The application will automatically:
1. Run database migrations
2. Serve static files via WhiteNoise
3. Start the Gunicorn server

## Initial Setup

To create a superuser for the Django admin:
1. Go to Railway dashboard
2. Open your project
3. Click on "Settings" → "Service Variables"
4. Add a new deployment with `python manage.py createsuperuser` command

## Access

- **Application**: Railway-provided URL (e.g., `https://your-app.railway.app`)
- **Admin Panel**: `https://your-app.railway.app/admin`

## Features

- Full Django admin panel
- Product management
- Order processing
- Customer management
